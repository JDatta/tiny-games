# Ones Twos

Ones Twos contains **Number Garden**, a mobile-first game that teaches two-digit addition by counting ones, trading groups of ten, and counting tens and hundreds.

Run it locally:

```sh
cd ones-twos
python3 server.py
```

Then visit `http://localhost:8080`. The standalone `index.html` can also be opened directly. Tap the glowing blocks to count, tap `?` to enter an answer, or hold `?` to run Solver. Use `?a=58&b=47` to load a specific problem.

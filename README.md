# Tiny Games

Tiny Games is a collection of small, focused browser games. Each game lives in its own directory and is designed to be easy to run, inspect, and share.

## Games

- [ones-twos](ones-twos/) — a mobile-first place-value addition game for children.

Open a game’s README for instructions and project-specific documentation.

# Product sense

## Who uses this

- **Learners:** early-elementary children practicing place value, addition, subtraction, and multiplication.
- **Parents and guardians:** oversee installation and local resets; release analytics choices remain a pending privacy decision.
- **Maintainers:** keep the curriculum, accessibility, privacy, and release path accurate.

## What problem it solves

Number Garden makes arithmetic concrete by representing Ones, Tens, and Hundreds as visible units and requiring learners to act through the correct place-value sequence. It provides a persistent twenty-level curriculum with review, guided Tutorial support, and no account or required online service.

## Product principles

- Make each operation’s roles and transformations visible: counting, carrying, borrowing, copying, converting, and regrouping.
- Permit only the next mathematically valid action; fast paths must preserve the same transitions.
- Reward manual typed completion, not automated Tutorial play.
- Keep the game usable offline and resilient when browser storage is unavailable.
- Treat accessibility and operation-correct language as core learning behavior rather than presentation polish.

## Non-goals

Number Garden is not an assessment platform, social game, ad product, classroom reporting system, cloud-sync service, or negative-number curriculum. It has no account, multiplayer mode, in-app purchases, or required backend.

## Glossary

| Term | Meaning |
| --- | --- |
| operation | Addition, subtraction, or multiplication; it controls arithmetic, flow, terminology, and theme. |
| addend / sum | Addition operands and result. |
| minuend / subtrahend / difference | Subtraction’s starting quantity, removed quantity, and result. |
| multiplicand / multiplier / product | Multiplication’s stationary source, consumable source, and result. |
| Ones / Tens / Hundreds | Visible place-value units worth 1, 10, and 100. |
| carrying | Addition regrouping of ten units into the next place. |
| borrowing | Subtraction trade of one Ten for ten Ones when needed. |
| Drop All | Addition/subtraction hold action for one active operand cell. |
| Pull All | Multiplication hold action that completes only the active multiplier-Ones group. |
| Tutorial | Guided completion of the real interaction path with no rewards or analytics. |
